**国自然标书的立项逻辑诊断——不代写，只诊断、重构、找风险。**

> ⚠️ **NSFC 明文规定不得使用生成式 AI 直接生成申请书正文。**
> 本 skill 的用途是**诊断、重构、找风险**，**不是代写**——
> 这不是风格偏好，是**合规要求**。

---

## 十层诊断

| # | 层 | 一句话 |
|---|---|---|
| 1 | 资助层级匹配 | 问题的规模**配得上**青年 C 吗？ |
| 2 | 问题合法性 | 是**真医学问题**，还是时髦的技术/数据？ |
| 3 | 机制主线 | 有没有一条**解释性的脊梁**？ |
| 4 | ⭐ **架构层次分离** | 八层有没有**互相失效**？ |
| 5 | 深度 vs 描述 | 是机制性的，还是描述性的？ |
| 6 | 创新纪律 | 创新**具体在哪一层**？ |
| 7 | 可行性与支撑 | 可行**不是平台数量** |
| 8 | ⭐ **评审视角扫描** | **必须同时给**最强支撑点与最可能被拒点 |
| 9 | 边界意识 | **该砍什么**——范围控制是优势不是妥协 |
| 10 | 战略收束 | 为什么是这个问题/角度/层级/现在 |

### ⭐ 第 4 层最重要

**永远分开这八层，不许互相失效**：

```
背景 → 空白 → 科学问题 → 假设/模型 → 目标 → 研究内容 → 技术路线 → 预期产出
```

**五处最常见的失效**：意义↔问题 · 问题↔目标 · 目标↔实验 · **内容↔方法** · **方法↔创新**

> 🔴 **链断在哪，就指出来。不要整篇重写——先定位断点。**

### 第 8 层有个硬要求

**每次都必须同时给出**「最强支撑点」与「最可能被拒点」——
**不许只给风险，也不许只给优点。**

## 医学科学部特有的三层

**C 口问「机制清不清楚」；H 口还要问「这对临床意味着什么、你做不做得成」。**

| # | 层 | 判据 |
|---|---|---|
| **11** | 临床落点 | 能不能说出「**研究做成了，临床哪一步会变**」？ |
| **12** | 队列可行性 | **可招募数 ≥ 样本量需求**，写具体数字做对比 |
| **13** | 伦理与合规 | 伦理批件 · 知情同意 · 弱势群体 · 数据管理 · 预注册 |

## 年度规则：**去哪取，不在哪**

> 🔴 本 skill **刻意不写任何年度性具体数字**。
> NSFC 每年改版——把篇幅/结构/代码写死，**1–2 年后不仅无用，还有害**。

**五处权威来源，按优先级**：当年《项目指南》 > 撰写提纲 > 医学科学部注意事项 > 依托单位 → **网上的"经验"永远是二手范式**。

## 表达层：标书去机器味

**一条规则：只改表达，不改事实。**

四层扫描（词语 → 句法 → 段落 → **章节**），逐层走不跳层。

### ⭐ 第 4 层的核心是「章节职责表」

| 章节 | 职责 |
|---|---|
| **立项依据** | 问题驱动，明确研究缺口 |
| **研究内容** | 研究动作、边界、步骤和验证口径 |
| **研究基础** | 按证据链写清已有结果与局限 |
| **工作条件** | 资源逐项对位到研究任务 |
| **风险应对** | 风险、触发条件、影响和备选方案 |

> **实测案例**：一份标注「立项依据」的文本，四段里**三段**在写技术流程与统计假设——
> 全是「研究内容」的职责。处置不是逐行润色，而是**先判定归属**。

### 🔴 token 保护（**这一项不可省**）

```bash
python scripts/check_token_diff.py <原文> <改写后>
```

比对 LaTeX 命令 / 引用 key / 数字与单位 / 状态 token / 路径 URL——
**丢失的必须逐个解释**。丢一个数字，就是改了一个事实。
