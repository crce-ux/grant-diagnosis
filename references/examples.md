## 一、章节职责错位（第 4 层，最重要）

### ❌ 不好

```
## 立项依据

本研究将采用 3T MRI 采集静息态数据，TR=2000ms，TE=30ms。
预处理用 DPABI，先做头动校正（阈值 0.5mm），再做空间标准化。
统计分析采用双样本 t 检验，多重比较用 GRF 校正，体素水平 p<0.001。
拟纳入 120 例，按 1:1 随机分组……
```

**标注「立项依据」，四段全在写技术流程、参数、统计假设——属于「研究内容」的职责。**
立项依据要回答的是「**为什么非做不可**」，这段一句都没有。

### ✅ 好

```
## 立项依据

TRS 患者约占精神分裂症的 20–30%，其中约 1/3 对氯氮平仍无应答，
而目前**没有任何经过验证的疗效预测指标**——临床只能靠 8–12 周的试错
（引文 1–4）。

现有影像预测研究多集中于皮层—皮层连接，**屏状核这一跨模态枢纽
在 TRS 中的角色尚未被系统检验**（引文 5–7）。本课题要回答的是：
**基线屏状核—前额叶连接能否在治疗前区分应答者与非应答者？**
```

**差在**：问题驱动、缺口写清楚、最后落到一个**疑问句形式**的科学问题。

> ⚠️ **归属调整属结构性改动，须人工确认，不得擅自搬移。**

## 二、创新点

### ❌ 不好

```
本课题创新性地采用多模态融合技术，构建了全新的分析框架，
实现了从数据到机制的完整闭环，具有重要的科学意义。
```

四个抽象标签堆在一起，**删掉后信息量为零**。
「多模态融合」是技术栈，不是科学深度。

### ✅ 好

```
与既有工作相比，本课题的差异有三点：
① 对象：既往研究纳入「精神分裂症」，本研究限定**氯氮平抵抗**这一亚群
   （定义见 1.2，依据 xxx 标准）；
② 指标：把屏状核从「感兴趣区之一」提为**主检验变量**，并预设其
   与丘脑—皮层环路的分离效应；
③ 验证：用**独立样本**验证预测模型，而非同一批数据的交叉验证。
```

**差在**：每条差异都可核查、可反驳；不是形容词，是**具体做法上的不同**。

## 三、年度性数值

### ❌ 不好

```
申请书正文（除摘要外）不超过 8000 字，参考文献不超过 50 篇。
青年项目申请人年龄不超过 35 周岁，资助期限 3 年。
```

**写在一个讲「怎么申报」的文档里，就是写死了年度性数值。**
NSFC 每年改版——照着过期的规矩写，比没有规矩更糟。

### ✅ 好

```
- [ ] 当年正文篇幅上限是多少？（**以当年撰写提纲为准**）
- [ ] 目标层级的当年名称与资格要求？
- [ ] 当年是否仍为包干制？
```

**差在**：给的是**问题**，不是数值。

## 四、表达层：四层扫描

### ❌ 不好

```
本研究首先进行数据采集，然后进行预处理，之后进行特征提取，
接着进行特征选择，再进行模型构建，最后进行验证，从而实现
从数据到临床决策的转化，构建起一个闭环的研究体系。
```

三处机器味：**八步以上的箭头式流程句**、**无主语**、
**「构建起一个闭环的研究体系」是元评论**——它在说「这段写得很好」。

### ✅ 好

```
本研究用基线结构像与静息态功能像，检验其能否在治疗前区分
应答者与非应答者。采集与预处理见 2.1；特征提取只保留
既往 meta 分析报告过的区域，以控制过拟合（见 2.3）。
```

**差在**：有主语（本研究）、有动作、有边界（为什么只保留既往 meta 分析报告过的区域）；
不再自我评价。

## 五、去味时的 token 保护

